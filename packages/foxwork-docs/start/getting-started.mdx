# 开始使用 SeeWayWork

打开 SeeWayWork 后，使用公司账号登录。登录成功后，客户端会同步公司提供的模型、MCP、Skills、插件和桌面策略，并自动连接属于你的远程工作区。

你也可以新增本地工作区，用于处理本机文件。首次读取文件夹、运行终端命令或控制桌面时，SeeWayWork 会要求你在本机确认权限。

公司资料、项目状态和待确认事项由 Brand Project OS 提供。AI 可以查询、分析和提出建议，但正式变化必须由有权限的员工确认。

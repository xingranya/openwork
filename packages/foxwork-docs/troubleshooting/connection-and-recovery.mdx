# 连接诊断与恢复

登录失效时，先重新登录公司账号。FoxWork 会撤销旧会话并按最新权限重新同步，不需要手工重新填写公司地址。

公司模型、MCP、Skills 或插件没有出现时，查看“设置 > 公司连接”的同步状态。若账号正常但能力仍为空，记录页面中的请求编号并交给公司管理员检查成员或团队授权。

个人远程工作区持续显示“正在连接”时，先确认公司服务可用，再重试连接。恢复后应继续使用同一个个人工作区，不重复创建多个工作区。断网期间可以继续使用不依赖公司服务的本地工作区。

任何诊断信息都不应包含完整密码、会话令牌或模型密钥。

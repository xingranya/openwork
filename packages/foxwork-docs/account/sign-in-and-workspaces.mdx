# 登录与工作区

员工从 FoxWork 的公司登录入口注册或登录。登录成功后，FoxWork 会自动连接属于你的远程工作区，不需要填写服务器地址或连接密钥。

个人远程工作区由公司 Den 管理，用来运行远程 AI 会话。它不是项目正式数据的唯一保存位置。项目的正式状态、审批和证据仍由 Brand Project OS 管理。

除自动建立的个人远程工作区外，你仍可继续新增本地或远程工作区。一个工作区连接失败不会删除其他工作区。

退出登录后，公司下发的模型、MCP、Skills、插件和远程工作区会停止使用。本地工作区和本机文件不会因此被删除。重新登录后，FoxWork 会按账号的最新权限重新同步。

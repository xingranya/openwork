# 公司能力与权限

登录公司账号后，SeeWayWork 会同步 Den 按成员或团队开放的模型、MCP、Skills 和插件。你只能使用账号和团队权限允许的能力；管理员也只能看到当前公司已登记的能力和管理入口。

Brand Project OS MCP 用于查询项目资料、分析证据和创建 Proposal。AI 只能创建待确认事项，不能替员工批准正式变化，也不能执行任意数据库查询或读取未授权的本机文件。

公司能力不可用时，先查看“设置 > 公司连接”中的账号、同步和诊断状态。不要把公司 MCP 重复添加为本地自定义连接，也不要向聊天中粘贴公司密钥。

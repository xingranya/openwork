# 项目资料与待确认事项

项目资料接入后，SeeWayWork 可以查询原件、解析结果和当前项目状态。重要结论应带回原件版本、SHA-256、页码、幻灯片页或音视频时间码。

新资料和新会议不会直接覆盖当前状态。AI 会生成增量 Proposal，并把需要决定的内容放入待确认事项。具备项目权限的员工确认后，Brand Project OS 才会记录正式事件并更新状态投影。

聊天记录、模型摘要、远程工作区文件和检索索引都不是正式事实。出现冲突时，以权威事件、审批记录和原件证据为准。
